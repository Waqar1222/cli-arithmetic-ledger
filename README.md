# py-logged-calculator

A robust, fault-tolerant Python Command-Line Interface (CLI) calculation engine featuring an automated, persistent transaction ledger system.

---

## 🚀 Key Features

* **Persistent Session History:** Automatically streams and serializes calculation data to an append-only text file (`calc_history.txt`).
* **Fault-Tolerant Architecture:** Built-in `try/except` exception handling catches bad inputs and prevents script crashes.
* **Mathematical Safeguards:** Prevents execution termination on edge-case exceptions like division by zero.
* **Streamlined UI/UX:** Features a continuous execution loop with intuitive navigation menus and clear operational separation.

---

## 🛠️ Built With

* **Python 3.x** - Core programming language
* **Native File I/O** - Persistent data storage (No external database dependencies)

## ⚙️ Step-by-Step Installation & Usage

Follow these steps to run the project locally on your machine.

### Prerequisites
Make sure you have Python installed. You can check your version by running:
```bash
python --version
```

### 1. Clone the Repository
Clone this repository to your local directory using Git:
```bash
git clone https://github.com
```

### 2. Navigate to the Directory
Move into the project folder:
```bash
cd py-logged-calculator
```

### 3. Run the Application
Execute the script using the Python interpreter:
```bash
python cli_arithmetic_ledger.py
```
